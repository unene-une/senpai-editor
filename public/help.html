Senpai Editor

執筆活動を加速させる、最強のテキストエディタ

クイックスタート

Senpai Editor は、作家やライターが執筆に集中できるよう設計された、シンプルかつ強力なエディタです。

ファイルの開き方

  • サイドバーの 「フォルダを開く」 から執筆プロジェクトのディレクトリを選択します。
  • .txt ファイルが自動的にリストアップされます。
  • ファイル名をクリックするとエディタで開きます。現在開いているファイルはサイドバーでハイライトされます。

保存と状態

  • Ctrl + S で現在のファイルを保存します。
  • 未保存の変更がある場合、サイドバーのファイル名の横に ● が表示されます。

執筆サポート機能

📜 原稿用紙カウント

文字数だけでなく、設定した「行数×文字数」に基づいた擬似的な「ページ数」をリアルタイムで計算します。新人賞の応募規定確認などに便利です。

🔍 高度な検索・置換

Ctrl + F で検索パネルが開きます。IMEの変換確定を待ってから検索を実行する、日本語入力に優しい設計です。

✅ 文章校正パネル

「て、に、を、は」の連続や、括弧の閉じ忘れ、三点リーダー（…）の個数などをチェックし、問題のある箇所へワンクリックでジャンプできます。

🌈 ダイナミックテーマ

ライト・ダークに加え、背景が透過する「Rainbow」や、自分好みの色を設定できる「Custom」テーマを搭載しています。

ショートカットキー一覧

Ctrl + S保存
Ctrl + Oフォルダを開く
Ctrl + F検索パネルを表示 / 非表示
Ctrl + N新規プロジェクト作成
Ctrl + ,設定を開く

困ったときは

ファイルが外部で更新された場合：

他のエディタでファイルが書き換えられた際、自動的に検知して再読み込みを促すダイアログが表示されます。

文字化けする場合：

Senpai Editor は UTF-8 と Shift-JIS を自動判別しますが、読み込みに失敗する場合は設定から適切なエンコーディングを確認してください。
