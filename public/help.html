クイックスタート

Senpai Editor は、作家やライターが執筆に集中できるよう設計された、先輩がかわいいエディタです。

📁 ファイルの開き方

  • サイドバーの 「フォルダを開く」 から執筆プロジェクトのディレクトリを選択します。
  • .txt ファイルが自動的にリストアップされます。
  • ファイル名をクリックするとエディタで開きます。現在開いているファイルはサイドバーで色付きで強調されます。

💾 保存と自動バックアップ

  • Ctrl + S で現在のファイルを保存します。未保存時は ● が付きます。
  • 新機能： 20分ごとにファイルの変更を自動的に保存します。執筆に夢中になってもデータは守られます。

珠玉の機能たち

🖋 縦書きモード対応

設定からワンクリックで縦書き表示に切り替え可能。日本語特有の美しさをそのままに、原稿用紙へ向かうような没入感を提供します。

📜 リアルタイム原稿換算

文字数だけでなく、設定した「行数×文字数×段組」に基づいた「ページ数」を瞬時に算出。公募の分量確認に強力な威力を発揮します。

🔍 大文字/小文字区別付き検索

Ctrl + F で検索パネルが展開。「Aa 大文字/小文字区別」チェックに対応し、正確な検索と一括置換を可能にします。

✅ 洗練された文章校正パネル

「て、に、を、は」などの連続した助詞や、括弧の閉じ忘れなどのミスを自動でピックアップ。ワンクリックで指摘箇所へジャンプできます。

🌈 エクストリーム・テーマ設定

ライト・ダークはもちろん、背景が透過する衝撃の「Rainbow」や、自分だけの完全オリジナルの色を構成できる「Custom」テーマを搭載。

📐 フレキシブルなUI

左サイドバーの幅は境界ドラッグで自由に調整でき、次回起動時にも記憶されます。作業環境は常に最適な状態に保たれます。

キーボード・ショートカット

Ctrl + S 現在のファイル上書き保存
Ctrl + O プロジェクトフォルダを開く
Ctrl + F 検索・置換パネルの表示
Ctrl + N 新規プロジェクト作成
Ctrl + , 設定（テーマ・縦書き等）を開く

トラブルシューティング

ファイルが外部で更新された場合：

他のエディタでファイルが書き換えられた際、自動的に検知して再読み込みを促すダイアログが表示されます。内容の競合を防ぐことができます。

文字エンコーディングの問題：

当エディタは UTF-8 と Shift-JIS を自動判別しますが、読み込み結果がおかしい場合は、正しい形式で保存されているか確認してください。
